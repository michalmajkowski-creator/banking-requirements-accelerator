# Requirement Linting

Apply deterministic checks first, then semantic checks when an approved model is available. Verify atomicity, clarity, necessity, feasibility, testability, measurability, traceability, owner, source, rationale, exceptions, and defined terminology. A quantitative NFR needs metric, threshold, conditions, and measurement point. Report rule ID, severity, evidence, and remediation; do not rewrite an approved requirement without review.
