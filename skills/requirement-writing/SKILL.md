# Requirement Writing

Runtime implementation is intentionally stubbed. The future implementation must create atomic, solution-independent, testable statements with rationale, owner, sources, priority, dependencies, acceptance criteria, and status. Mark all generated items as draft and route them to a Business Analyst; never promote drafts to source-of-truth automatically.
